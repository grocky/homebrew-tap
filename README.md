# grocky/tap

Homebrew formulae for my tools.

```sh
brew install grocky/tap/gh-contrib-tui
```

| Formula | Project |
| --- | --- |
| `gh-contrib-tui` | [grocky/gh-contrib-tui](https://github.com/grocky/gh-contrib-tui) |

Formula versions are bumped by each project's release workflow, and every change
here is audited, built from source and tested on macOS and Linux.
